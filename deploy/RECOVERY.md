# Recovery runbook (AWS RDS PostgreSQL)
Enable encrypted RDS automated backups and point-in-time recovery; proposed retention 14 days. Restrict snapshot access and do not export customer data to developer laptops. Configure CloudWatch alarms for database storage, connections and application 5xx; alert on failed email queue entries using the owner control center until automated metrics are deployed.
Restore to a separate isolated RDS instance, never overwrite the original. Disable checkout and email worker, use separate test credentials, validate migration checksums, row counts, order allocations and recall records. Run smoke and integration tests before switching application database credentials. Record recovery duration and recovered timestamp. Test quarterly. No backup or restore has been executed by this release.
