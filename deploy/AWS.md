# AWS staging deployment runbook (not provisioned)
Use ECR, ECS Fargate in private subnets, an internet-facing ALB with ACM certificate, and private RDS PostgreSQL with encryption, automated backups and deletion protection. Use Secrets Manager for DATABASE_URL and ADMIN_PASSWORD; restrict RDS ingress to ECS security group. Set APP_ORIGIN to the exact HTTPS origin. Keep all feature flags false. Run migrations as a separate task against a NEW empty database; do not run on an existing untracked schema. Route ALB health checks to /api/health. Configure CloudWatch logs, alarms and AWS WAF rate limits. Test restore into an isolated RDS instance. Configure DNS only after staging acceptance. Do not enable commerce: production payment gate is intentional. Individual administrator identities, MFA, RBAC, audit logs and full integration tests are still required. No AWS resources are created by this package.
